# Roadmap

## Gate 0 — Reproducible baseline

- [x] Exact rank-at-least-29 equation and points.
- [x] Dependency-free local mod-2 independence certificate.
- [x] Independent SageMath and Magma height computations.
- [x] Saturation evidence through every prime below 4096.
- [x] Canonical candidate schema, hashes, provenance, and adversarial audit.

## Gate 1 — Exact structural reductions

- [x] Multiquadratic branch-genus theorem.
- [x] Complete character-packet rank decomposition.
- [x] One-function principal-divisor visibility barrier.
- [x] Torsion packet-capacity bounds.
- [x] Canonical-fibration rigidity for `chi != 2`.
- [x] Certified split `E8` rational elliptic surface.
- [x] Degree-three genus-one rank-capacity theorem.
- [x] Cyclic trisection shell and projected `A2(2)` theorem.
- [x] Exact `E8/3E8` trace-code incidence counts.
- [x] Exact ranks of tested cyclic cubic bases with Sage proof flags.
- [x] Minimal-character scale obstruction for the degenerate `mu=2` marking.
- [x] Full geometric rank ceiling `12` for the entire `mu=2` cubic-base family.
- [x] Generic six-channel capacity vector `(4,6,4,4,6,6)`.
- [x] Reduction of geometric rank 30 to simultaneous K3 ranks `(4,6,6)`.

## Gate 2 — Picard-maximal marking sieve

- [x] Implement exact finite-field probes for the three K3 channels.
- [x] Reject `mu = 3, 4, 5, 13/11` using the good reduction at `p=17`.
- [ ] Complete the `k20` maximal-residue scans modulo 11, 13, and 17.
- [ ] Intersect the maximal residue classes across good primes.
- [ ] Rationally reconstruct low-height markings satisfying the congruence sieve.
- [ ] Test all three K3 channels only on reconstructed survivors.
- [ ] Retain markings attaining `(4,6,6)` at every completed good prime.
- [ ] Compute characteristic-zero Picard numbers or explicit K3 sections.
- [ ] Prove simultaneous Picard maximality for one marking.

## Gate 3 — Rational descent and a positive-rank base

- [ ] Choose a positive-rank cubic scale, initially `c=3`.
- [ ] Construct the six character lattices over the appropriate rational twists.
- [ ] Descend the three K3 eigenspaces from geometric to rational sections.
- [ ] Assemble 30 generic directions and compute the exact height matrix.
- [ ] Determine the ternary/Eisenstein gluing and saturation.

## Gate 4 — Trace-code fallback and independent construction

- [ ] Enumerate all 2240 maximal totally isotropic trace codes.
- [ ] For one code, construct the 240 minimal trisection linear systems.
- [ ] Solve the square-discriminant cyclicity locus exactly.
- [ ] Compute the normalization and Jacobian of surviving covers.
- [ ] Canonicalize covers and detect repeated trisection fibres.
- [ ] Produce the first common cover carrying at least two independent orbit planes.
- [ ] Escalate the maximum Hermitian rank toward 11.

## Gate 5 — Rational specialization and final certificate

- [ ] Specialize away from bad fibres and specialization exceptions.
- [ ] List 30 complete rational points on one curve over `Q`.
- [ ] Prove exact independence by finite reductions or descent.
- [ ] Compute rigorous heights and a nonzero determinant.
- [ ] Saturate at every necessary prime.
- [ ] Rerun independently in SageMath and Magma.
- [ ] Publish the machine-checkable Level-5 package.

## Parallel workstreams

- Recover the complete executable second rank-17 K3 fibration.
- Search split degree-31 norm identities over `Q`.
- Analyze the three K3 channels as isotrivial/Delsarte surfaces and connect
  simultaneous Picard jumps to CM or isogeny loci.
- Use finite-characteristic calculations only as rigorous rejection sieves or
  lifting guides.
- Improve quotient-height and covering-curve point searches.

The project does not infer impossibility from record age, failed searches, or
probabilistic rank heuristics.
