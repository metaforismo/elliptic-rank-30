# Final certificate contract

A Level-5 result must contain:

1. a global minimal Weierstrass model;
2. 30 complete rational points;
3. exact equation verification;
4. rational torsion determination;
5. a rigorous canonical-height matrix;
6. positive definiteness and nonzero determinant;
7. an independent exact linear-independence proof by reduction or descent;
8. necessary saturation analysis;
9. independent SageMath and Magma verification;
10. machine-readable data, hashes, software versions, and search provenance.

The theorem required is only `rank E(Q) >= 30`; an exact upper bound is
optional.
