# Truth-status semantics

- **false** — contradicted by an exact argument or computation.
- **incomplete** — potentially correct but missing indispensable steps.
- **heuristic only** — supported only by scores, statistics, or conjectural
  models.
- **restricted obstruction** — rigorously rules out a specified mechanism or
  family.
- **new representation** — exact reformulation without a new theorem yet.
- **new intermediate theorem** — rigorously proved result advancing the search.
- **candidate construction** — explicit object requiring remaining
  certification.
- **certified rank at least 30** — explicit curve and 30 rigorously independent
  rational points, independently verified.
