# Search policy

1. Reproduce and preserve the current record certificate.
2. Use several mathematically independent construction families.
3. Rank candidates by visible independent points and certification cost, not by
   one analytic score.
4. Treat Selmer rank as an upper-bound mechanism until coverings are globally
   solved.
5. After a failed batch, measure the bottleneck and change representation
   before merely increasing bounds.
6. Never promote finite-field, floating-point, or learned-model output into a
   rank claim without exact characteristic-zero verification.
