# Security and integrity policy

This repository contains mathematical search and certification code.  Please
report privately any issue that could invalidate a claimed certificate,
including malformed coordinates, silent floating-point coercion, incorrect
finite-field group laws, hash/provenance mismatches, integer overflow,
unsound proof flags, or a discrepancy between independent systems.

Do not describe heuristic or characteristic-p evidence as a rank statement
over `Q`.  The strongest accurate truth status must be preserved at all times.
